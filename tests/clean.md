# TurboSync

TurboSync connects your existing tools and automates repetitive work. It is
for teams that want a simpler way to run their operations.

## What it does

TurboSync moves tasks between your tools without manual work. You define the
rules once. TurboSync runs them for you.

## Setup

1. Install TurboSync.
2. Connect your accounts.
3. Create a rule.
4. Start the rule.

You do not need training to use TurboSync. Most teams set it up in one hour.
